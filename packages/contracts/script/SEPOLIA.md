# Sepolia runbook (owner, real network, your own wallet)

0. Rehearse first, before any real transaction, with no ETH on a local fork: `SEPOLIA_RPC_URL=… script/demo-sepolia-fork.sh` (port 8546, anvil test keys), stop with `script/demo-sepolia-stop.sh`. It writes `deployments/11155111.fork.json` (gitignored), never `deployments/11155111.json`; it rehearses the scripts, not the app. Never run DeploySepolia again after the real deploy without DEPLOY_OVERWRITE; it would replace the real deployment record (the fork rehearsal writes only its own `.fork.json`, so it cannot).
1. Get Sepolia ETH from a faucet into your wallet `$ME`. In `packages/contracts`: `export SEPOLIA_RPC_URL=https://ethereum-sepolia-rpc.publicnode.com` (or your own node; keep it in env, never in a file). Every command below prompts for your key (`--interactive`; `--account <name>` works too). Paste the key only at that prompt.
2. stETH: `cast send 0x3e3FE7dBc6B4C189E7128855dD526361c49b40Af "submit(address)" 0x0000000000000000000000000000000000000000 --value <ETH> --rpc-url $SEPOLIA_RPC_URL --interactive`
3. wstETH: `ST=$(cast call 0x3e3FE7dBc6B4C189E7128855dD526361c49b40Af "balanceOf(address)(uint256)" $ME --rpc-url $SEPOLIA_RPC_URL | awk '{print $1}')`, then `cast send 0x3e3FE7dBc6B4C189E7128855dD526361c49b40Af "approve(address,uint256)" 0xB82381A3fBD3FaFA77B3a7bE693342618240067b $ST --rpc-url $SEPOLIA_RPC_URL --interactive` and `cast send 0xB82381A3fBD3FaFA77B3a7bE693342618240067b "wrap(uint256)" $ST --rpc-url $SEPOLIA_RPC_URL --interactive`.
4. WETH: `cast send 0xfFf9976782d46CC05630D1f6eBAb18b2324d6B14 "deposit()" --value <ETH> --rpc-url $SEPOLIA_RPC_URL --interactive`
5. Deploy: `FOUNDRY_OUT=out-demo FOUNDRY_CACHE_PATH=cache-demo forge script script/DeploySepolia.s.sol --rpc-url $SEPOLIA_RPC_URL --broadcast --skip test --interactive --sender $ME` (writes `deployments/11155111.json`, `orders: []`; refuses if that file already has shipped orders unless `DEPLOY_OVERWRITE=1`).
6. Ship: `SHIP_WETH_DEPOSIT=<wei> SHIP_WSTETH_DEPOSIT=<wei> FOUNDRY_OUT=out-demo FOUNDRY_CACHE_PATH=cache-demo forge script script/ShipSepolia.s.sol --rpc-url $SEPOLIA_RPC_URL --broadcast --skip test --interactive --sender $ME`. Deposit sizes are yours to set (defaults: 0.05 WETH per order, wstETH value-balanced at the live rate); your wallet must hold at least one order's deposit of each token. Orders go to 1inch's Sepolia router `0x1111113db0e0ef9d0e3a50d5f094a3a57a26c0de` (`USE_ONEINCH_ROUTER=false` = our RateSpaceAquaRouter). A second ship needs a new `SHIP_SALT` (default 1).
7. ABIs: `bun run scripts/build-demo-abi.ts 11155111`. The app reads `deployments/11155111.json` and `deployments/11155111.abi.json`; commit both after the real deploy.
